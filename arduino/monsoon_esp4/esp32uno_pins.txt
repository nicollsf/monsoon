GIOP34-39:  input only, no pull-up
ESP32: Only pins that support both input & output have integrated pull-up and pull-down resistors. Input-only GPIOs 34-39 do not.
All GPIO pins on esp32 can handle interrupts
All pins that can act as outputs can be used as PWM pins (GPIOs 34 to 39 can't generate PWM)
ADC2 required for wifi/bluetooth radio
DS18B20: 2k2-4k7 pull-up to 3.3V with Vcc 5V is fine
